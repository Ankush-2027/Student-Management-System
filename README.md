\# Student Management System



A full-stack Student Management System developed using JavaScript, Node.js, Express.js, MongoDB and Mongoose.



\## Features



\- Add student

\- View students

\- Update student

\- Delete student

\- MongoDB database integration

\- REST API

\- Frontend and backend integration

\- Student validation



\## Technologies Used



\### Frontend

\- HTML

\- CSS

\- JavaScript

\- Fetch API



\### Backend

\- Node.js

\- Express.js

\- REST API



\### Database

\- MongoDB

\- Mongoose
